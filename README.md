This repository contains a collection of Python scripts designed to process and transform different types of data files, including CSV, JSON, and plain text formats. Each Python module focuses on a specific task—such as parsing structured datasets, cleaning raw text inputs, converting between formats, or preparing data for downstream workflows—making the project a flexible toolkit for handling diverse data sources. Together, these files demonstrate a variety of Python techniques for reading, validating, transforming, and organizing data in a reproducible way.
